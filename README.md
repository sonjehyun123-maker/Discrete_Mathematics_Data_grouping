# Discrete_Mathematics_Data_grouping

# 1. 과제 개요

## 프로젝트명
데이터 그룹핑 (Data Grouping)

## 과제 목표

2차원 좌표 데이터를 생성한 뒤,  
좌표들을 2개의 그룹으로 반복적으로 분류하여 최종 그룹을 완성하는 프로그램 구현.

---

# 2. 프로그램 목표

프로그램은 다음 기능을 수행한다.

1. 중복 없는 랜덤 좌표 200개 생성
2. 좌표를 임의로 2개 그룹으로 분리
3. 각 그룹의 평균 좌표 계산
4. 모든 좌표와 그룹 평균 간 거리 계산
5. 더 가까운 그룹으로 재분류
6. 평균값 갱신
7. 평균값이 더 이상 변하지 않을 때까지 반복
8. 최종 결과를 CSV 파일로 저장

---

# 3. 전체 알고리즘 구조

```text
1. 랜덤 좌표 생성
↓
2. 초기 그룹 분할 (100개 / 100개)
↓
3. 그룹 평균 계산
↓
4. 모든 좌표에 대해:
    그룹1 평균과 거리 계산
    그룹2 평균과 거리 계산
↓
5. 더 가까운 그룹으로 재배치
↓
6. 새로운 평균 계산
↓
7. 이전 평균과 동일한가?
    YES → 종료
    NO  → 반복 (5번으로)
```

---

# 4. 데이터 구조 설계

현재 프로젝트에서는 다음 구조체를 사용한다.

```c
typedef struct GroupNode {
    int x[MAX_POINTS];
    int y[MAX_POINTS];
    int c[MAX_POINTS];

    double average1[2];
    double average2[2];
} GroupNode;
```

---

## 구조체 역할

| 변수 | 역할 |
|---|---|
| x[ ] | x좌표 저장 |
| y[ ] | y좌표 저장 |
| c[ ] | 그룹 번호 저장 (1 또는 2) |
| average1 | 그룹1 평균 좌표 |
| average2 | 그룹2 평균 좌표 |

---

# 5. 프로그램 흐름 설계

## STEP 1. 랜덤 좌표 생성

### 목적

0~400 사이의 랜덤 좌표 200개 생성.

### 조건

- 좌표 중복 금지
- x, y 모두 정수

### 구현 방식

- 모든 좌표를 배열에 저장
- Fisher-Yates Shuffle 사용
- 앞의 200개 추출

---

# 6. 초기 그룹 분할

생성된 200개의 좌표를:

- 앞의 100개 → 그룹1
- 뒤의 100개 → 그룹2

로 임시 분류한다.

```text
0 ~ 99   → 그룹1
100~199 → 그룹2
```

---

# 7. 평균값 계산

각 그룹에 대해:

- x 평균
- y 평균

을 계산한다.

평균 좌표는 그룹의 중심점 역할을 수행한다.

---

## 평균 공식

그룹1 평균:

```math
\bar{x}_1 = \frac{\sum x}{n}, \quad \bar{y}_1 = \frac{\sum y}{n}
```

그룹2도 동일 방식 사용.

---

# 8. 거리 계산

각 좌표와 그룹 평균 사이의 거리를 계산한다.

거리 계산은 유클리드 거리 공식을 사용한다.

```math
d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}
```

---

## 거리 비교 방식

```text
거리1 < 거리2
→ 그룹1

거리2 < 거리1
→ 그룹2
```

즉:

더 가까운 평균을 가진 그룹으로 이동한다.

---

# 9. 그룹 재분류 과정

모든 좌표에 대해 반복 수행한다.

```text
for 모든 좌표:
    거리1 계산
    거리2 계산

    if 거리1 < 거리2:
        그룹1
    else:
        그룹2
```

---

# 10. 평균 갱신

재분류 완료 후:

- 그룹1 평균 재계산
- 그룹2 평균 재계산

을 수행한다.

---

# 11. 반복 종료 조건

직전 평균과 현재 평균이 동일하면 반복 종료.

```text
이전 평균 == 현재 평균
→ 종료
```

실수 오차를 고려하여:

```c
fabs(a - b) < 0.0001
```

형태 사용.

---

# 12. 함수 구조 설계

## 1) 거리 계산 함수

```c
double distance(int x1, int y1,
                double x2, double y2);
```

역할:
- 좌표와 평균점 사이 거리 계산

---

## 2) 평균 계산 함수

```c
void calculateAverage(GroupNode* gNode);
```

역할:
- 그룹1 평균 계산
- 그룹2 평균 계산

---

## 3) 그룹 재분류 함수

```c
int regroup(GroupNode* gNode);
```

역할:
- 모든 좌표를 다시 그룹화
- 그룹 변경 여부 반환

---

## 4) CSV 저장 함수

```c
void saveCSV(GroupNode* gNode);
```

역할:
- 최종 결과를 CSV 파일로 저장

---

# 13. 반복 구조 설계

```c
while (1)
{
    이전 평균 저장

    regroup()

    calculateAverage()

    평균 비교

    같으면 break;
}
```

---

# 14. CSV 저장 구조

최종 결과는 다음 형식으로 저장한다.

```csv
x,y,group
120,30,1
55,200,2
```

Excel에서 시각화 가능하도록 구성한다.

# 15. 구현 시 주의사항

반복마다:

```c
tx1 = ty1 = tx2 = ty2 = 0;
```

초기화 필요.

---

## 2. 그룹 개수 초기화 필수

```c
cx1 = cx2 = 0;
```

초기화 필요.

---

## 3. 실수 비교 주의

```c
a == b
```

직접 비교 금지.

---

## 4. 무한루프 주의

종료 조건 정확히 구현 필요.

# 16. 프로젝트 핵심 개념

본 프로젝트의 핵심은:

- 반복 기반 그룹화
- 중심점(centroid)
- 거리 기반 분류
- 군집화(clustering)

이다.

이는 실제 머신러닝 분야의:
- K-Means
- 데이터 마이닝
- 패턴 분석

의 기초 개념과 연결된다.
